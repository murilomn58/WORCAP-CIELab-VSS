# WORCAP · CIELab VSS

Repositório de apresentação do trabalho sobre espaços de cor e segmentação visual preparado para o WORCAP.

## Estado do repositório

A versão pública contém esta apresentação. O código experimental ainda está em preparação local e não faz parte desta entrega.

O trabalho local reúne experimentos com espaços de cor, agrupamento, modelos de rede, métricas e figuras para o artigo. Esses componentes serão documentados junto da versão de código correspondente.

## Reprodutibilidade

Ainda não há instruções de execução para a versão pública. Scripts, dependências, dados de exemplo e resultados deverão acompanhar a publicação do código para permitir a reprodução dos experimentos.
